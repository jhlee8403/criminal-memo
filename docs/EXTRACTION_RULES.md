# 피고인별 변호인과 생년월일 처리

이 문서의 규칙은 초기 주민번호 구분값/체크섬 정책과 ‘변호인 항목 누락은 공란’ 정책을 대체합니다.

## 데이터·추출·검토

`Defendant`는 이름, `birthDigits`(YYMMDD), `statedAge`, 사용자가 직접 확인한 `confirmedBirthYear`, `birthRequiresReview`, `CounselInfo`, 죄명 및 구속 상태를 별도로 저장합니다. 주민번호 뒷자리는 피고인 모델에 저장하지 않습니다. 원문 PDF 및 원문 추출문에는 원래 번호가 그대로 남아 있을 수 있지만 계산·성별·세기·체크섬 판단에는 전혀 사용하지 않습니다.

피고인 번호 뒤의 U+200B 등 보이지 않는 문자를 제거하고, 다음 피고인 또는 공소사실 시작 전까지를 해당 피고인의 구간으로 봅니다. 페이지 경계에서 구간이 끊기지 않습니다. 변호인·죄명·구속을 다른 피고인에게 넘기지 않습니다.

검토 화면에서 피고인별 생년월일 앞 6자리, 기재 나이, 확인한 출생 연도, 변호인 상태·이름, 죄명·구속을 수정합니다. 편집하면 기존 검토 확인 및 생성 PDF가 무효화됩니다.

## 변호인

| 상태 | 출력 | 확인 |
|---|---|---|
| 이름 기재 | 원문 이름 (예: 윤상일(국선)) | 일반 검토 |
| 없음 명시 | X | 일반 검토 |
| 정상 판독한 피고인 구간에 항목 없음 | X | 일반 검토 |
| 빈 항목·상충 정보·판독 불가 | 공란, 생성 차단 | 직접 상태 선택 |
| OCR로 판독한 문서 | 자동 확정하지 않음 | 이름/없음/미기재를 원문과 대조해 선택 |

텍스트 PDF라도 판독 실패·불완전한 텍스트 레이어가 있을 수 있습니다. 판독 신뢰성은 호출자가 전달하며, 현재 앱은 OCR 사용 시 보수적으로 모든 피고인에게 확인을 요구합니다. 어떤 손상된 문서에서도 기재 누락과 판독 누락을 완벽히 자동 구별하는 기능은 아닙니다. 읽기 실패는 오류로 보고합니다.

복수 피고인의 변호인 출력은 `1. 윤상일(국선)\n2. X`처럼 피고인 번호와 대응합니다. 칸을 넘는 이름은 잘라내지 않고 생성 오류를 냅니다.

## 생년월일·세기·나이

1. 앞 6자리는 정확히 6개의 ASCII 숫자여야 합니다. 월·일의 달력 유효성을 검증합니다. 윤일은 실제 해석한 연도에서 다시 검증합니다.
2. **뒷자리 7자는 사용하지 않습니다.** 구분값·성별·국내/외국인 분류·체크섬 판정도 하지 않습니다.
3. 확인한 출생 연도가 있으면 YY와 일치하고 실제 달력에 존재하며 기소일보다 늦지 않은지 검사합니다. 잘못된 수동 입력을 지우거나 자동 해석으로 대체하지 않습니다.
4. 사용자 확인 연도가 없으면 기재 나이 N과 기소일 연도 Y를 이용하여 출생 연도 후보 `Y-N-1`, `Y-N` 중 YY와 일치하는 연도를 찾습니다. 이는 기재 나이를 세기 판단의 근거로 쓰는 단계입니다. 후보가 하나가 아니면 확정하지 않습니다. 임의의 최대 나이/기본 1900년대를 가정하지 않습니다.
5. 후보의 월·일과 기소일로 정확한 만 나이를 계산합니다. 기재 나이와 다르면 **미확정 후보**와 불일치 경고를 표시하며, 직접 출생 연도를 확인하기 전에는 나이 원을 적용하지 않습니다.
6. 명시적으로 확인한 연도에서 계산 나이가 기재 나이와 달라도 경고는 유지합니다. 원문을 확인한 생년월일을 기준으로 표시할 수 있습니다.
7. 기재 나이 또는 기소일이 없거나 서로 맞지 않아 세기를 결정할 수 없으면 직접 확인을 요구합니다. OCR로 추출한 생년월일·기재 나이도 자동 확정하지 않습니다.

표시: 만 19세 **미만**이면 소년, 만 70세 **초과**이면 필요적국선. 정확히 19세·70세는 표시하지 않습니다. 복수 피고인 중 조건을 충족하는 확정 결과가 하나라도 있을 때 해당 문구를 감쌉니다. 미확정 결과 자체로 원을 만들지 않습니다.

## 최신 샘플의 결과

| 피고인 | YYMMDD | 기소일 | 기재 나이 | 해석 | 변호인 |
|---|---|---|---:|---|---|
| 이민주 | 841204 | 2025.08.22 | 41 | 1984.12.04 후보 → 만 40세. 불일치·연도 확인 필요 | X (없음 명시) |
| 김유나 | 720324 | 2026.10.27 | 54 | 1972.03.24 → 만 54세 | 윤상일(국선) |
| 이영수 | 710305 | 2026.10.27 | 55 | 1971.03.05 → 만 55세 | X (항목 미기재) |

`BirthDateResolver`는 해석 결과와 경고를 반환하며, 세기·성별·체크섬 검사를 수행하던 기존 `ResidentNumber` 구현은 제거했습니다. 테스트에서 뒷자리를 임의의 숫자·마스킹·다른 문자열로 바꿔도 결과가 동일한지 확인합니다.

핵심 테스트와 좌표 시뮬레이션은 Linux에서 실행합니다. Apple 통합 테스트 및 검토 화면·iOS 출력은 Xcode/실기기에서 별도로 검증해야 합니다.
