공소장 PDF를 오프라인으로 분석하여 원본 형사메모 양식에 기입하는 iPadOS 앱의 1차 구현과 새 변호인/생년월일 규칙 반영입니다. 최신 공소장 샘플(main 69ca759)을 병합하였으며 원본 형사메모와 기존 이력은 보존했습니다.

- PDFKit 텍스트 추출·Vision OCR, SwiftUI 원문 대조·수정, PDF 미리보기·파일 저장·공유
- 피고인별 변호인/죄명/구속 구간 분리. 변호인 이름, 없음 명시 X, 항목 미기재 X. OCR/판독 불확실이면 직접 확인 전 생성 차단
- 주민번호 앞 6자리만 사용. 뒷자리 구분값·체크섬 로직 제거. 기재 나이·기소일·사용자 확인 출생 연도로 세기 해석. 나이 불일치 경고와 미확정 상태의 나이 원 차단
- 실제 샘플: 이민주 841204는 만 40세 후보와 기재 41세 불일치. 김유나 720324는 만 54세·윤상일(국선), 이영수 710305는 만 55세·X
- 복수 피고인의 죄명은 각각 번호와 이름을 표시하며 변호인·구속 출력 번호는 피고인 번호와 대응

검증: Linux Swift XCTest 44개 및 실제 PDF 좌표·보존 검사 38개 통과. Swift 구문 파싱 통과. Apple 통합 테스트 7개는 작성했지만 Xcode/Apple SDK/iPad가 없어 미실행입니다. iOS 렌더러·Vision OCR·실기기 저장/공유의 성공을 주장하지 않습니다.
