# 실제 PDF 분석 및 좌표

공소장 샘플 기준 커밋: `69ca75939bfe16294d68c855abbdbba8cb45b046`. 형사메모 원본은 초기 분석 이후 변경하지 않았습니다.
세 PDF는 `Resources` 폴더가 아닌 저장소 최상위에 있으며 파일명은 Unicode NFD입니다. 앱은 원본과 동일한 바이트의 `memo-template.pdf` 사본을 사용합니다. 공소장은 테스트 번들에만 포함합니다.

이민주는 출생 연도를 직접 확인하기 전까지 나이 조건을 적용하지 않습니다. 김유나·이영수는 기재 나이와 계산 나이가 일치하여 출생 세기를 해석할 수 있습니다. 뒷자리 구분값과 체크섬은 사용하지 않습니다. [처리 규칙](EXTRACTION_RULES.md) 참고.

피고인 번호 뒤의 보이지 않는 문자를 정리하고 피고인별 구간을 분리하여, 다음 페이지로 이어지는 죄명과 변호인 항목 누락을 구분합니다. 변호인·구속 출력은 피고인 번호로 대응합니다. 입력 좌표는 아래와 동일하며 공간이 부족하면 잘라내지 않고 오류를 냅니다.

## 양식과 좌표계

형사메모: 1페이지, 회전 0°, MediaBox 원점 (0,0), 크기 **595.000122×841.000122 pt** (A4 근사값). PDF 입력 필드가 없는 고정 표 양식입니다. 원본 페이지·표를 재작성하지 않고 원본 PDF 페이지 위에 내용을 그립니다.

좌표의 단위는 PDF point(1/72인치), **왼쪽 위가 원점**, x는 오른쪽, y는 아래 방향입니다. `UIGraphicsPDFRenderer`의 텍스트 그리기 좌표와 동일합니다. 하단 원점 PDF 좌표가 필요하면 `yPDF = pageHeight - y - height`로 변환합니다. 원본 페이지는 CGContext의 y축을 뒤집어 그린 뒤 텍스트용 상단 좌표로 복원합니다.

| 입력 항목 | x | y | 너비 | 높이 | 하단 원점 y |
|---|---:|---:|---:|---:|---:|
| 피고인 목록 | 33 | 128 | 140 | 111 | 602.000122 |
| 죄명 목록 | 180 | 78 | 151 | 161 | 602.000122 |
| 검사 | 385 | 48 | 112 | 22 | 771.000122 |
| 변호인 | 385 | 78 | 112 | 20 | 743.000122 |
| 기소일 | 231 | 247 | 174 | 20 | 574.000122 |
| 구속 표시 | 537 | 48 | 25 | 22 | 771.000122 |
| 소년 문구를 감싸는 원 | 174 | 730 | 26 | 15 | 96.000122 |
| 필요적국선 문구를 감싸는 원 | 109 | 746 | 56 | 15 | 80.000122 |

구속 O: 중심 (549.5,59), 반지름 7pt, 빨강, 선 두께 1.8pt. 소년·필요적국선: 위 사각형에 내접하는 빨간 타원, 선 두께 1.3pt. 날짜는 좁은 “기소일” 제목 칸이 아닌 그 오른쪽 빈 칸에 입력합니다. 죄명은 제목 아래 세로 빈 칸, 피고인은 피고인 제목 아래 빈 칸입니다.

실행 코드와 분석 스크립트가 같은 [template-layout.json](../Sources/MemoCore/Resources/template-layout.json)을 읽습니다. 좌표는 해당 원본의 SHA-256과 결합되어 있습니다. 다른 양식으로 리소스만 교체하면 생성이 중단되며, 새 양식 좌표의 재분석이 필요합니다. 원본이 여러 페이지인 경우 모두 그리는 루프를 사용하지만, 현재 업로드된 양식은 한 페이지이며 다른 양식은 해시 검증을 통과하지 않습니다.

## 좌표 검증 결과와 한계

`python scripts/verify_pdfs.py` 실행: **38개 검사 통과**.

- 번들 템플릿과 원본 바이트 일치, 원본 세 파일 불변 확인.
- 입력 사각형이 원본 페이지 안에 있고, 원래 글자와 표 선을 침범하지 않음.
- 두 원의 범위 안에 원본 “소년”·“필요적국선” 글자 경계가 들어감.
- 가상 값의 줄바꿈·기입 위치 확인. 원본과 시뮬레이션을 2배 래스터화했을 때 입력 영역 밖(선 두께를 위한 2pt 여유)의 변경 픽셀 **0개**.
- Swift 테스트용 추출문이 실제 두 공소장 PDF에서 얻은 텍스트와 정확히 일치.

[좌표 표시도](coordinate-map.png) · [가상 값 출력 시뮬레이션](coordinate-simulation.png) · [검증 보고서](pdf-validation.json)

시뮬레이션은 **PyMuPDF**가 생성한 좌표 검토 자료이며 앱의 실제 출력물이 아닙니다. 두 나이 원은 위치 확인을 위해 강제로 표시한 것이며 실제 샘플 판정 결과가 아닙니다. 한글 폰트·자간·줄높이는 iOS와 다릅니다. Swift/iOS 출력, 실제 인쇄 배치, 여러 페이지의 실제 iOS 출력 보존은 아직 실행 검증하지 않았습니다. Mac의 `ApplePDFTests` 및 생성 PDF 첨부파일로 후속 확인해야 합니다.
