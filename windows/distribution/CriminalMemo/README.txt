Criminal Memo — 사건번호·공소장 일괄 생성 시험판

실행과 지원 범위
ZIP을 먼저 압축 해제한 뒤 CriminalMemo.html을 Microsoft Edge로 여세요.
Edge 104.0.1293.47을 지원 대상으로 기존 legacy 호환 빌드를 유지했습니다.
실제 회사 Windows Edge 104에서는 아직 시험하지 못했습니다. 개발용 Chromium 103 및 API 제거 환경의 시험 결과를 실제 회사 PC 성공으로 단정하지 않습니다.
사용자 PC에 인터넷, 별도 프로그램 설치, 관리자 권한, 서버 실행을 요구하지 않습니다. 데이터는 창의 메모리에서 처리합니다.

1. 여러 공소장 선택
공소장 PDF를 여러 개 선택하면 파일별 목록이 생성됩니다. 다시 선택하면 이전 목록이 교체됩니다.
파일명에 2026고단203948 또는 2025고정1382 같은 사건표시가 있어야 합니다. 법원명과 뒤 문구는 없어도 됩니다.
사건번호가 없거나 서로 다른 사건번호가 여러 개 있으면 그 파일은 생성하지 않습니다. 파일명을 확인해 다시 선택하세요.
메모 상단 사건 칸과 저장 파일명에는 공소장 내용이 아닌 파일명의 사건표시를 사용합니다.

2. 파일별 첫기일
각 파일에 날짜와 시간을 모두 입력하세요. 이 버전은 저장 파일명의 시간도 필요하므로 둘 다 필수입니다.
날짜: 20261118 또는 2026-11-18 (2026.11.18, 2026. 11. 18.도 지원).
시간: 1000 또는 10:00. 24시간제를 사용합니다.
첫 번째 파일의 날짜를 수정하면 나머지 모든 날짜에도 복사됩니다. 나중에 개별 수정한 날짜도 다시 덮어쓰므로 주의하세요.
시간은 자동 복사되지 않습니다. 각 파일마다 개별 입력하세요.
존재하지 않는 날짜/시간이나 부분 입력은 해당 행에 오류로 표시됩니다.
첫기일은 메모에 2026. 11. 18. / 10:00의 두 줄로 출력합니다.
첫기일 외 공소장 정보의 수동 입력은 제공하지 않습니다.

3. 전체 분석·메모 생성
버튼을 누르면 파일을 차례로 분석하고 사건별 1페이지 메모를 만듭니다.
목록에 분석 중, 생성 중, 생성 완료 또는 오류 사유가 표시됩니다. 한 파일 오류가 나도 나머지 파일은 계속 처리합니다.
'이 파일 보기'와 공소장/생성 메모/추출 텍스트 버튼으로 항목별 내용을 확인하세요.
입력값을 바꾸면 해당 메모는 무효화되고 ZIP에서도 제외됩니다. 첫 번째 날짜를 바꾸면 복사 대상 전체가 무효화됩니다.
처리 중 입력값이 바뀐 파일도 이전 설정의 메모를 게시하지 않습니다. 최신 입력으로 전체 분석을 다시 실행하세요.
원문 파일과 이전에 다운로드한 PDF는 삭제하지 않습니다.

4. 저장
단일 선택: 1000 2026고단203948.pdf 같은 PDF를 저장합니다.
다중 선택: criminal-memo-batch.zip 하나를 저장하며 내부에 사건별 PDF가 들어 있습니다. 실패한 파일은 포함하지 않습니다.
앞부분은 첫기일 시간(HHmm), 뒷부분은 파일명 사건표시입니다. 날짜와 Windows 금지 문자 ':'는 파일명에 넣지 않습니다.
사건번호와 시간이 같아 저장 이름이 중복되면 오류로 처리하며 덮어쓰지 않습니다.
목록의 생성 개수와 오류 항목을 확인하고 저장하세요. ZIP을 풀고 PDF의 사건번호·첫기일·이름·표시를 확인한 후 사용하세요.

5. 구속·필요적국선·소년
명시적 불구속은 검은 X, 구속은 빨간 O입니다. 날짜/체포일이 들어간 지원 구속 표기도 인식합니다.
고정 사건에서 구속여부 항목 자체가 없으면 X로 처리합니다. 값이 비었거나 모호한 항목을 불구속으로 추측하지 않습니다.
복수 피고인은 순서대로 OX/XX/OO처럼 출력합니다.
누구라도 구속이면 필요적국선에 빨간 동그라미를 한 번 표시합니다.
확정 가능한 나이가 기소일 기준 70세 이상이면 필요적국선, 19세 미만이면 소년에 표시합니다.
YYMMDD만으로 세기를 확정하지 않습니다. 문서에 명시된 전체 생년월일이 앞 6자리와 일치하고 기소일과 모순되지 않는 경우에만 세기 근거로 사용합니다.
주민번호 뒷자리, 공소장 기재 나이, 임의의 세기 기준은 사용하지 않습니다. 근거가 부족하면 나이 표시를 보류합니다.
국선변호인 이름(국선), 법무법인명) 이름 이름 형식은 유지합니다.

6. 오프라인·오류
텍스트가 거의 없는 페이지에는 기존 OCR을 사용합니다. 필요하면 전체 OCR을 선택할 수 있습니다.
OCR의 검토 필요 상태 등 필수 자동 추출이 불확실한 파일은 기존 규칙대로 생성이 보류될 수 있습니다.
PDF는 기존대로 파일당 50MB, 100페이지 이하를 지원합니다.
ERR_BLOCKED_BY_ADMINISTRATOR 또는 Worker/WebAssembly/CSP/다운로드 오류는 문구와 실행 경로를 회사 IT 담당자에게 전달하세요.
브라우저 보안 기능 해제나 파일 보안 정책 우회를 해결책으로 사용하지 마세요.
