Criminal Memo — 새 2페이지 양식·전체 메모 저장·본문 기소일 시험판

프로그램 배포 ZIP을 압축 해제하고 CriminalMemo.html 하나를 Microsoft Edge로 여세요.
새로 제공된 2페이지 형사메모 원본 전체, 글꼴, PDF/OCR 라이브러리와 데이터가 HTML 안에 내장되어 있습니다.
별도의 양식 PDF 선택, 인터넷 연결, 설치, 관리자 권한, 서버 실행은 필요하지 않습니다.
사용자는 이전 44a0d39의 공소장 분석·2페이지 생성·표시가 회사 Edge 104에서 동작함을 확인했습니다.
이번 버전의 회사 PC 실행과 폴더 쓰기 정책은 개발 환경에서 직접 검증하지 못했습니다.

1. 공소장 선택과 첫기일
PDF를 여러 개 선택하면 원본 파일명과 사건번호가 있는 파일별 목록을 만듭니다. 다시 선택하면 목록이 교체됩니다.
파일명에 2026고단1001 또는 2026고정1003 같은 사건번호가 있어야 합니다.
없거나 서로 다른 사건번호가 여러 개면 그 파일은 생성하지 않습니다.
각 파일의 첫기일 날짜와 시간을 모두 입력하세요. 날짜는 20261118, 2026-11-18 또는 점 구분 형식,
시간은 1000 또는 10:00을 지원합니다. 날짜는 첫 파일을 바꾸면 나머지에 복사되지만 시간은 복사하지 않습니다.
첫기일 외 수동 입력은 제공하지 않습니다.

2. 전체 분석·메모 생성
파일을 순차 분석하여 사건별로 정확히 2페이지 PDF를 생성합니다.
첫 페이지는 새 원본의 좌표에 사건번호·자동 추출 정보·첫기일을 기재합니다.
특기사항과 소년/국참/필요적국선은 새 위치인 첫 페이지 중하단에 표시합니다.
첫기일은 하단 재판진행상황 표 첫 번째 기일 칸에 YYYY. M. D.와 HH:mm 두 줄로 출력합니다.
두 번째 페이지에는 어떤 정보도 추가하지 않고 새 원본 그대로 유지합니다.
파일별로 생성 상태와 추출 실패 항목 이름을 보여 줍니다. 실패한 항목은 추측하지 않고 빈칸으로 생성합니다.
파일명 오류·손상 PDF·내장 양식 오류 등 생성 전제가 없으면 생성 실패로 구분하고 나머지는 계속 처리합니다.
기소일은 명시적인 기소일 항목을 우선하고, 그 외에는 검찰청 아래의 본문 날짜를 사용합니다.
열람복사용 다운로드일시·제출일시는 달라도 기소일을 무효화하지 않습니다. 본문 후보끼리 충돌하거나 근거가 없으면 비워 둡니다.
범죄일시·구속일·체포일을 기소일로 대신하지 않습니다.

3. 전체 메모 저장 — ZIP으로 묶지 않습니다
'전체 메모 저장'을 누르세요. 저장 폴더가 없으면 폴더 선택창이 먼저 열립니다.
공소장과 같은 폴더를 원하면 그 폴더를 직접 선택하고 쓰기 권한을 허용하세요.
이미 폴더를 선택했다면 한 번의 클릭으로 생성된 메모 전체를 그 폴더에 순서대로 기록합니다.
각 파일의 쓰기와 닫기가 성공한 후에만 저장 완료로 표시합니다.
파일명은 기존대로 1000 2026고단1001.pdf입니다. 날짜는 넣지 않고 시간의 ':'를 제거합니다.
이름이 같은 기존 파일은 덮어쓰거나 삭제하지 않습니다. 충돌을 해당 사건의 저장 실패로 알립니다.
현재 입력의 메모를 같은 폴더에 이미 저장한 경우에는 중복 기록하지 않습니다.
일부 파일 쓰기에 실패해도 나머지는 계속 처리합니다. 실패한 행의 사유를 확인하고 '이 메모 폴더 저장'으로 재시도할 수 있습니다.
필요하면 '저장 폴더 선택'으로 다른 폴더를 지정하세요. 새 폴더 선택 시 그 폴더 기준으로 저장 상태를 다시 관리합니다.

화면 요약은 전체 공소장 수, 생성 성공 수, 저장 성공 수, 저장 실패 수, 추출 경고 사건 수를 보여 줍니다.
생성 실패와 아직 저장하지 않았거나 보류한 수도 별도로 표시합니다.
추출 경고가 있는 메모도 저장할 수 있습니다. 정보 추출 실패, PDF 생성 실패, PDF 저장 실패는 서로 다른 상태입니다.
저장 작업 중에는 날짜·시간 편집을 잠가 이전 입력값을 현재 저장 결과로 오인하지 않도록 합니다.

4. 폴더 저장을 사용할 수 없는 경우
회사 정책이나 브라우저에서 폴더 접근을 막으면 각 사건의 '이 메모 다운로드' 또는 '다음 메모 다운로드'를 사용하세요.
다음 버튼은 클릭 한 번에 하나만 요청하며 자동 다중 다운로드를 강제하지 않습니다.
'다운로드 요청됨'은 저장 완료가 아닙니다. 실제 저장 여부는 Edge 다운로드 목록과 폴더에서 확인하세요.
다운로드 경로는 브라우저 설정/대화상자가 정합니다. 앱이 원본 공소장 경로를 알아내지 않습니다.
보안 정책을 해제하거나 우회하지 마세요. 취소·미지원·권한 거부를 저장 성공으로 처리하지 않습니다.

5. 기존 표시 규칙과 수정 후 재생성
소년은 피고인 순서대로 빨간 O(만 19세 미만), 검정 X(만 19세 이상), 미확정 공백입니다.
국참은 지정 네 죄명에 따른 자동 분류이며 최종 법적 판단이 아닙니다. 대상이 확인되면 O,
모든 죄명이 완전하고 대상이 없으면 X, 불완전하면 빈칸입니다.
소년·국참 표시는 인쇄된 글자 중앙에 크게 겹치며 복수 문자열은 칸에 맞춰 축소합니다.
필요적국선은 누구라도 구속 또는 확정 만 70세 이상이면 빨간 원을 한 번 표시합니다.
나이는 기소일을 기준으로 앞 6자리와 뒤 첫 숫자(1~4)로 계산합니다. 나머지 뒤 여섯 숫자는 가립니다.
주민번호·기소일이 불완전하거나 OCR 검토가 필요하면 나이 표시를 보류합니다.
첫기일을 바꾸면 생성·현재 저장 상태를 무효화합니다. 이미 디스크에 쓴 파일은 삭제하지 않습니다.
최신 입력으로 다시 생성하되 같은 이름의 기존 파일 충돌 시 다른 폴더를 선택할 수 있습니다.

6. 오프라인과 검증 범위
기존 OCR 엔진, 국선 이름(국선), 법무법인명) 이름 이름, 구속 OX와 자동 파서를 유지합니다.
PDF는 파일당 50MB, 1~100페이지를 지원합니다. 원본 공소장과 양식을 다시 그리거나 수정하지 않습니다.
개발 검증은 Linux Chromium 103의 file 실행과 최신 API 제거 환경을 사용합니다.
폴더 선택·쓰기 UI의 자동화 검사는 모의 핸들을 사용했으며 실제 회사의 네이티브 폴더 권한 정책을 보장하지 않습니다.
창을 닫으면 메모리의 문서·결과·폴더 선택 상태는 사라집니다. 필요한 PDF를 저장하고 내용을 확인한 후 사용하세요.
