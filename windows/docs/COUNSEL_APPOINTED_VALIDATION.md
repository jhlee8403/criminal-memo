# 국선·일반 변호인 직함 및 출력 보완

기준 브랜치 `experiment/v1-auto-latest-pdf`, 기준 커밋 `c170dd1`.
날짜: 2026-11-15.

## 동작

- `국선변호인 변호사 김가상`, `국선변호인 김가상`, `변호인 국선변호사 김가상`
  → `김가상(국선)`.
- `변호사 김가상`, `변호인 변호사 김가상` → `김가상`.
- 제목·직함·이름이 다른 줄이어도 처리하며 기존 `김가상(국선)` 및 별도 줄의
  `( 국선 )`도 지원한다. 명시된 국선 근거가 없는 일반 변호인에는 국선 표시를 붙이지 않는다.
- 법무법인의 `태평양) 이름 이름 …` 형식과 이름 순서는 그대로 유지한다.
- 이름 누락·성명불상·선임예정·판독불가 등은 `needsReview`와 빈 이름을 반환한다.
  자동 생성 검증을 우회하거나 임의의 이름을 채우지 않는다.
- 변호인 없음·미기재·국선변호인 없음은 빈칸을 유지한다.

변호인 파서의 제목 인식을 공통 항목 수집기의 경계에 연결했다. 이는 `국선변호인`
또는 `변호사`로 시작하는 독립 항목이 앞선 구속여부/죄명 등에 이어 붙는 것을 막기 위한
변호인 경계 처리이다. 이미 변호인 항목을 수집 중이면 직함 줄은 계속 같은 값에 속하므로
v1.4 법무법인 담당변호사 목록의 줄 연결을 유지한다.

검사·기소일·피고인·죄명·구속의 개별 파서 규칙, OCR, PDF 렌더러, UI,
원본 PDF는 변경하지 않았다. 수동 입력 기능도 추가하지 않았다.

## 검증

- `npm test`: **83개 통과**. 기존 법무법인·기타 항목 회귀에 더해 국선 제목 변형,
  일반 직함 제거, 줄바꿈, 국선 근거 없는 일반 이름, 불명확한 이름 보류를 검사한다.
- `tests/fixtures/counsel-output-cases.json`의 **15개 가상 사례**를 전체 공소장 텍스트에
  삽입해 파싱하고 변호인 결과와 다른 주요 필드의 보존을 검증했다.
- `npm run build`, `npm run test:browser`: 통과. 각 사례를 텍스트 PDF로 생성해
  File API 입력 → PDF 텍스트 추출 → 자동 정보 추출 → 기존 1페이지 메모 자동 생성 →
  다운로드까지 수행했다. 국선·일반·법무법인 각각 최종 PDF를 생성했다.
- `python scripts/verify_outputs.py`: **100개 통과**. PyMuPDF로 15개 다운로드 PDF의
  변호인 칸 전체 문자열·원문 순서·국선 접미 표시·칸 내부 좌표를 검사한다.
  각 사례의 변호인 칸 밖 메모 픽셀은 기준 메모와 동일하다.
- 기존 실제 샘플 2개, 스캔/혼합 PDF OCR 회귀도 통과했다. 원본 및 배포 템플릿은 보존된다.
- 보고서: `appointed-counsel-browser-report.json`, `appointed-counsel-pdf-report.json`.

새 테스트는 가상 인명을 사용한다. 실제 최신 공소장 전체의 정확도를 보장하지 않는다.
현재 이름 판별은 지원하는 한글 이름 형태와 불명확 표현에 대한 보수적인 검사이며,
실존 인물 확인 기능이 아니다. 지원하지 않는 이름/표현은 판정을 보류한다.

Linux 관리 정책 `ERR_BLOCKED_BY_ADMINISTRATOR`로 `file://` 탐색이 차단되어 동일 HTML을
메모리에 올려 브라우저 검증을 수행했다. Windows Edge 더블클릭 실행은 미검증이다.
