# 실제 확인 구조 재현 기반 파서 v1.3 검증

기준: `experiment/v1-auto-latest-pdf` / `aa895f2`. 날짜: 2026-11-15.

사용자가 설명한 최신 문서 구조를 `tests/fixtures/latest-structure-v13.txt`에 재현했다.
새 자료의 인명은 홍길동·김가상·박가상·이가상, 주민번호 뒷자리는 `XXXXXXX`,
주소·사건번호는 가상 자리표시자이다. 실제 최신 PDF 원문이나 개인정보는 추가하지 않았다.
기존 PDF와 기존 샘플 텍스트는 수정하지 않았다.

## 변경

- `(인)`, `( 인 )`, `(서명)`, `( 서명 )`과 이름 줄 분리를 지원하며 검사 이름만 반환.
- 검찰청/공소청 명칭 바로 아래 날짜를 `body` 근거로 분석. 기소일·공소제기일의
  명시값은 `explicit`, 제출일시는 `submission`으로 구분하여 반환.
  `FilingDateParser.assess()`는 `date`, `reason`, `candidates`를 제공하고 기존
  `parse()`는 확정 날짜/`null` 반환을 유지한다.
- 다운로드일시·범죄일시·구속일을 기소일로 채택하지 않는다. 제출일시는 독립된
  기소일 근거로 사용하지 않는다. 본문/기소일 후보가 충돌하거나 제출일시와
  다르거나 제출일시가 판독되지 않으면 날짜를 보류하고 원인을 검증 오류에 표시한다.
- `Ⅰ . 피고인 관련사항`, `Ⅱ . 공소사실`, `Ⅲ . 첨부`의 Unicode/ASCII 로마숫자,
  공백·마침표 변형을 처리. 공소사실/첨부 이후는 기본사항 수집에서 제외.
- 열람복사용 안내·출력자·다운로드/제출일시 머리말 및 페이지 번호를 연속 필드에서 제외.
- 다음 줄의 `( 음주운전 )`은 앞의 `도로교통법위반`과 결합하고 괄호 주변 공백을 정리.
  괄호 밖 쉼표는 죄명을 나누고 적용법조에서 죄명 수집을 멈춘다.
- 변호인의 `firm`과 `lawyers`를 구분하며, 법무법인 표현이 있으면 메모용 `name`에는
  명시된 담당변호사 이름만 담는다. 법무법인명만 있으면 변호사 이름을 추측하지 않고
  검토 필요 상태로 보류. 명시적 변호인 없음/기재 없음의 기존 빈칸 정책 유지.

OCR·PDF 텍스트 추출기·렌더러·화면·나이 판정 구현은 변경하지 않았다.
수동 입력 없이 필수 자동 추출이 완료될 때 기존 메모를 생성한다.
YYMMDD, 기재 나이, 주민번호 뒷자리로 세기를 추정하거나 나이 원 표시를 추가하지 않는다.

독립된 범죄/구속 날짜를 확정하지 않는지 검증했다.

## 테스트 결과

- `npm test`: **63개 통과**. 기존 38개와 신규 25개.
  검사·날짜·피고인·죄명·변호인·구속의 각 파서 반환값을 직접 검증한다.
  Unicode 구역 경계, 반복 머리말, 복수 피고인 분리, 날짜 충돌 사유,
  기재 나이와 뒷자리 마스킹 변화에 영향받지 않는 미확정 나이도 검사한다.
- `npm run build`: 오프라인 단일 HTML 생성.
- `npm run test:browser`: 가상 텍스트로 생성한 **3페이지 텍스트 PDF**를 실제 File API로
  입력하고, PDF 텍스트 추출 → 자동 파싱 → **기존 1페이지 메모 생성** → Blob 다운로드.
  수동 입력/확인 버튼을 사용하지 않았으며 이름·날짜·두 죄명·변호사·불구속을 검증했다.
- 기존 공소장1/2 자동 생성, 스캔 PDF 한글 OCR, text/image 혼합 PDF 회귀 통과.
  외부 HTTP 요청 0건, 브라우저 오류 0건.
- `python scripts/verify_outputs.py`: **39개 통과**. 다운로드 PDF를 PyMuPDF로 독립 검사.
  v1.3 결과의 검사 이름만 출력, 본문 날짜, 피고인, 정확한 두 죄명, 담당변호사,
  검은 X, 나이 표시 보류, 입력칸 밖 원본 양식 픽셀 보존을 확인했다.
- 배포 템플릿은 저장소 원본과 바이트 동일. 원본 PDF 변경 없음.
- 실행 보고서: [parser-v13-browser-report.json](parser-v13-browser-report.json),
  [parser-v13-pdf-report.json](parser-v13-pdf-report.json).

## 검증 한계 및 사용

실제 최신 문서 원문을 실행한 결과가 아니다. 사용자가 확인한 구조를 개인정보 없는
자료로 재현한 결과로, 모든 실제 공소장의 정확도를 보장하지 않는다. 현재 규칙은
알려진 항목명/제목과 본문 날짜 문맥에 의존하며, 임의 다단 표·다른 머리말 문구·
판독 불가 OCR을 일반적으로 복원하지 않는다.

Linux Chromium의 관리 정책(`ERR_BLOCKED_BY_ADMINISTRATOR`)이 `file://` 탐색을 차단하여
동일 배포 HTML의 메모리 진단으로 검증했다. Windows Edge 더블클릭/실제 회사 PC
오프라인 실행은 미검증이다.

실험 브랜치 푸시로 GitHub Actions의 파서 테스트·빌드·ZIP 아티팩트 업로드가 실행된다.
해당 실행의 `CriminalMemo-v1-auto-only` ZIP을 다운로드하여 압축을 풀고
`CriminalMemo.html`을 연다. 아티팩트 보관 기간은 기존 설정대로 14일이다.
