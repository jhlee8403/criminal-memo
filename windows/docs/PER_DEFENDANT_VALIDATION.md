# 필요적국선·국참 피고인별 판정 및 죄명 통합 출력 검증

기준 `3375e0d`, 새 브랜치 `experiment/v1-mandatory-counsel-per-defendant`. 기존 브랜치 및 2페이지 원본 PDF는 보존합니다.

## 네 사유와 피고인별 국참

`mandatoryAssessment()`가 피고인마다 구속, 기소일 기준 19세 미만, 70세 이상, 지정된 세 죄명을 각각 확인합니다. `birthAssessment()`와 기존 연령 상수를 그대로 사용합니다. 주민등록번호는 기존처럼 앞 6자리와 세기 판별용 첫 숫자만 사용하며 나머지 뒷자리는 저장/출력하지 않습니다.

한 사유라도 확인되면 빨간 O입니다. X는 불구속, 확정된 19~69세, 해당 피고인에게 귀속이 확인된 완전한 죄명 목록과 지정 죄명 없음이 모두 확인되어야 가능합니다. 나이·구속·죄명 귀속/완전성 중 필요한 정보가 빠지면 공백과 피고인별 경고입니다. 정보가 불완전해도 구속·소년·고령 또는 본인에게 적용되는 지정 죄명이 확인되면 O를 표시합니다.

특정 죄명은 요청한 세 문자열만 사용합니다. 도주치사·위험운전치사는 일치하고 도주치상은 필요적국선의 죄명 사유가 아닙니다. `보건범죄단속에관한특별조치법`은 일치하지만 `보건범죄단속에관한특별조치법위반`은 요청 문자열과 달라 일치하지 않습니다. 공백과 괄호 정규화는 기존 `normalizedCharge()`이며 부분문자열 검색을 하지 않습니다.

`juryGlyphs()`는 기존 네 가지 국참 죄명을 피고인마다 검사합니다. 본인의 정확한 대상 죄명은 O, 귀속과 죄명 목록이 모두 확인된 비대상은 X, 나머지는 공백입니다. 두 배열은 원래 피고인 순서를 유지하고 각 문자 색상도 독립적입니다. 이전 집계형 `juryGlyph()`/`ageMarks()`는 기존 호출 호환 테스트용으로 남아 있지만 PDF·화면의 새 판정에는 사용하지 않습니다.

## 기존 파서 경로의 문제와 귀속 검증

기존 `DefendantParser.split()`는 다음 피고인 항목까지의 줄을 각 피고인 구역으로 수집했습니다. 여러 인적사항 뒤에 공통 죄명란이 하나만 있으면 그 죄명이 마지막 피고인 구역에 들어갈 수 있었습니다. 이 위치만으로 마지막 피고인에게 적용된다고 확정해서는 안 됩니다.

파싱 후 귀속 검증 단계를 추가했습니다. `chargeAttribution: 'confirmed' | 'unknown'`, `chargesComplete`, `unassignedCharges`, `chargeOrder`로 귀속·완전성·표시 순서를 분리합니다. 귀속 메타데이터가 없는 데이터도 죄명 사유의 O/X 근거로 신뢰하지 않습니다.

| 가상 문서 유형 | 처리 |
|---|---|
| 각 피고인 구역에 별도 죄명란 | 구역 순서로 귀속 확인 |
| 공통란의 `김가상: 죄명`, `피고인 김가상: 죄명` | 기존에 추출한 이름과 정확히 대조해 연결 |
| 공통란의 `죄명(김가상)` | 괄호 안이 알려진 피고인 이름일 때만 연결 |
| `김가상, 이가상: 죄명`, `피고인 전원: 죄명` | 명시된 피고인에게만 연결 |
| 인적사항 뒤의 귀속 표시 없는 공통 죄명 | 마지막 또는 모든 피고인에게 배정하지 않음 |
| 인적사항 앞의 공통 죄명 | 이름으로 확인되는 귀속만 연결; 그 외 공통 목록에 보존 |
| 명시된 범위와 미확인 범위가 혼합 | 확인된 양성 사유는 사용 가능하나 미확인 목록 때문에 X를 확정하지 않음 |

모든 피고인의 별도 죄명란이 있는 일반 구역형은 기존 구역 경계를 사용합니다. 일부 구역에 죄명이 없고 마지막 구역에만 한꺼번에 있는 경우에는 공통란일 가능성을 배제할 수 없어 보류합니다. 지원하는 명시적 이름/전원 형식 밖의 복잡한 표, 번호 참조, 본문을 해석해야만 알 수 있는 귀속 관계까지 추론하지 않습니다. 이 때문에 실제로는 구역별 적용이 맞는 문서도 보수적으로 보류할 수 있습니다. 실제 문제 공소장은 제공되지 않았으므로 가상 구조 검증을 실제 문서 전체의 정확도로 일반화하지 않습니다.

반의사불벌·친고죄는 사건 전체에서 해당 죄명이 있는지 표시하는 기존 방식입니다. 미귀속 공통 죄명도 이 두 항목의 기존 양성 표시 근거로 보존합니다. 국참과 필요적국선의 피고인별 죄명 사유에만 확인된 귀속을 요구합니다.

## 출력용 죄명 통합

`memoChargeLines()`는 출력용 새 목록만 만들며 `defendants[].charges`를 변경하지 않습니다. 정규화한 전체 죄명을 키로 삼고 최초 등장 순서, 피고인 순서, 동일 피고인의 중복 제거를 유지합니다. 공통란에서 두 번째 피고인의 죄명이 먼저 등장하면 그 원문 순서도 보존합니다. 단일 피고인은 기존 형식을 유지합니다. 미귀속 죄명은 삭제하거나 임의의 이름을 붙이지 않고 `(귀속 미확인)`으로 표시합니다.

예시(두 피고인 모두 불구속·42세, 귀속/죄명 완전):

| 정보 | 변경 전 | 변경 후 |
|---|---|---|
| 김가상 → 특수상해, 절도 / 이가상 → 절도 | 특수상해 (김가상), 절도 (김가상), 절도 (이가상) | 1. 특수상해(김가상) / 2. 절도(김가상, 이가상) |
| 국참 | 사건 전체 O 한 개 | OX |
| 필요적국선 | 표시 없음 | XX |

도주치사가 김가상에게만 적용되고 이가상은 절도이면 국참 OX, 필요적국선 OX입니다. 반대로 두 번째 피고인에게만 적용되면 각각 XO입니다. 구속/소년/고령 사유로 필요한 경우 국참 결과와 달라질 수 있습니다.

## PDF 좌표와 표시

원본을 렌더링하고 글자 단위 좌표를 추출했습니다. 기존 텍스트 span은 필요적국선과 국참을 한 줄에 묶고 있었으므로 span 전체가 아닌 `필요적국선` 다섯 글자의 bbox를 별도로 측정했습니다.

- `markTextRects.mandatory`: `[111.299675, 513.352417, 49.892479, 9.951843]`
- `markFitRects.mandatory`: 위 글자 영역 중심의 폭 54pt, 높이 12pt
- 국참의 기존 글자/배치 사각형은 유지

기존 단일 필요적국선 타원을 제거하고 `fitOverlayMarks()`로 필요적국선과 국참 배열을 각각 그립니다. 글자 수에 따라 자동 축소하고 실제 폰트 윤곽 중심을 맞춥니다. 판정불가 자리는 동일 폭 슬롯으로 유지합니다. O는 빨강, X는 검정입니다. 반의사불벌·친고죄 타원은 유지합니다. 죄명란 좌표도 그대로이며 기존 글자 크기 조절과 줄바꿈을 사용합니다.
