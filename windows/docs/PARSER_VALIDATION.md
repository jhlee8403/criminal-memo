# 자동 추출 파서 개선 검증 (2026-11-15)

> 이 문서는 `aa895f2` 단계의 기록입니다. 후속 v1.3은
> [실제 확인 구조 재현 검증](PARSER_V13_VALIDATION.md)을 참고하세요.

기준 브랜치: `experiment/v1-auto-latest-pdf`, 변경 전 커밋 `18f0557`.

## 범위

OCR, PDF 텍스트 추출기, 화면, PDF 렌더러 및 나이 판정 로직은 변경하지 않았다.
항목명과 값의 줄 분리, 콜론 뒤 공백 없음, 항목명 사이 Unicode 공백,
날짜 구분자 주변 공백과 분리된 날짜, 반복/번호형 피고인, 별도 주민번호 줄,
번호 없는 여러 줄 죄명 및 괄호 안 줄바꿈을 파서에서 처리한다.
죄명 안 괄호 내부 쉼표는 보존하고 다음 항목명/공소사실에서 수집을 멈춘다.
명시된 기소일이 유효하지 않거나 서로 충돌하면 헤더 날짜로 임의 대체하지 않는다.

수동 입력은 추가하지 않았다. 자동 추출 필수 항목이 충족될 때 기존 1페이지
형사신건메모를 자동 생성한다. OCR 결과의 기존 불확실성 처리와 나이 원 표시
보류 정책도 유지한다. GitHub Actions에서 파서 테스트 후 단일 HTML을 빌드해
`CriminalMemo-v1-auto-only` 다운로드 ZIP 아티팩트를 제공한다.

최신 공소장 원문이 아니다. 같은 문서를 변경 전 `core.js`와 변경 후 파서에 입력했다.

|---|---|---|
| 검사 | 추출 실패 | 홍길동 |
| 기소일 | 추출 실패 | 2026-11-05 |

| 김가상 죄명 | 상해, 절도 (다른 피고인 죄명 혼입) | 사기, 도로교통법위반(음주운전) |

이 비교로 실제 최신 공소장의 정확도 향상률을 계산하지 않는다.

## 실행한 검사

- `npm ci`, `npm test`: 38개 통과. 변경 전 테스트는 37개 중 10개 실패했다.
  실패 10개는 이전 수동 연도 확인/나이 추론 정책의 기대값이 남아 있었기 때문으로,
  해당 기대값을 현재 자동 전용 정책(세기/나이 미확정)에 맞췄다. 나이 계산 구현은 그대로다.
- `npm run build`: 오프라인 단일 HTML 빌드 성공.
- `python scripts/prepare_fixtures.py`: 기존 PDF 원문과 저장된 텍스트 fixture 일치 확인,
  원본을 수정하지 않고 스캔/혼합 시험 PDF 생성.
- `npm run test:browser`: Linux Chromium 156의 offline context에서 기존 실제 PDF
  2개의 File API 입력 → 텍스트 추출 → 파싱 → 자동 메모 생성 → Blob 다운로드 통과.
  합성 형식 문서도 실제 렌더러로 1페이지 PDF 생성 확인.
- 스캔 PDF 한글 OCR 및 text/image 혼합 PDF 피고인·죄명 연결 회귀 검사 통과.
  OCR 결과는 기존대로 검토 필요 상태이며 수동 입력 우회 경로는 없다.
- `python scripts/verify_outputs.py`: 29개 통과. 실제 브라우저 다운로드 PDF의
  한글 이름/번호, 변호인, 구속 O/OX 색상/위치, 글꼴 포함 및 입력칸 밖 변경 픽셀 0 확인.
  배포 템플릿은 저장소 원본과 바이트 동일. 합성 2페이지 템플릿의 두 번째 페이지도 보존.
- 외부 HTTP 요청 0, 브라우저 실행 오류 0.
- 자세한 실행 결과: `parser-browser-report.json`, `parser-pdf-report.json`.

기존 샘플의 검사/날짜/피고인별 죄명은 변경 전후 동일하게 유지된다.
공소장1: 이민주, 상해·폭행치상, 이승엽, 2025-08-22.
공소장2: 김유나(공무집행방해) / 이영수(상해·절도), 이정현, 2026-10-27.

## 검증 한계

사용자가 문제를 보고한 **최신 공소장 원문은 확인되지 않았다**. 저장소의 기존
공소장1/2와 합성 사례를 대상으로 한 결과이며 최신 문서 정확도가 검증됐다는 뜻이 아니다.

관리 정책 `ERR_BLOCKED_BY_ADMINISTRATOR`로 실제 `file://` 탐색이 차단되어,
동일 배포 HTML의 메모리 진단을 수행했다. Windows Edge 더블클릭/실제 오프라인 PC는 미검증이다.

알려진 항목명 중심의 파서이므로 임의 다단 표, 항목명이 없는 공통 죄명 배정,
괄호 등 연결 근거가 없는 단어 중간 줄바꿈, OCR 오독을 일반적으로 복원하지는 않는다.
모호하거나 필수 항목이 누락된 문서는 기존 자동 생성 실패 경로로 처리한다.

`VALIDATION.md`와 기존 `browser-report.json`/`pdf-report.json`은 이전 개발 단계의
기록이다. 현재 실험 브랜치의 나이 정책과 실행 결과는 본 문서 및 parser 보고서를 기준으로 한다.
