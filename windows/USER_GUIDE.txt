Criminal Memo — Windows · Microsoft Edge 오프라인 배포 후보 v2.1

중요한 검증 상태
- 이 버전의 실제 Windows Edge HTML 더블클릭(file://) 실행은 아직 검증하지 못했습니다.
- 개발 환경 Chromium은 관리자 URL 정책으로 file:// 탐색을 차단했습니다.
- 브라우저 메모리 진단에서 인터넷 차단 상태의 PDF 읽기·한글 OCR·검토·PDF 생성·다운로드는 검증했습니다. 이것이 file:// 성공을 뜻하지 않습니다.
- 현재 저장소의 형사메모 원본은 1페이지입니다. 출력은 모든 원본 페이지를 보존합니다. 지시서에 적힌 실제 2페이지 원본은 아직 제공되지 않았습니다.

1. 복사와 실행
CriminalMemo 폴더 전체를 USB나 로컬 디스크에 복사하세요. ZIP 파일인 경우 반드시 압축을 먼저 풀어 주세요.
CriminalMemo.html을 더블클릭하거나, 우클릭 → 연결 프로그램 → Microsoft Edge로 여세요.
Node.js, npm, Python, Xcode, 서버 실행, 관리자 권한은 필요하지 않도록 구성했습니다. 사용자 데이터는 서버에 업로드하지 않습니다.
브라우저 정책에 따라 로컬 HTML, Blob Worker, WebAssembly 또는 다운로드가 차단될 수 있습니다. 이를 허용하는 회사 정책이 필요합니다.

2. 공소장 불러오기
'공소장 PDF'에서 로컬 파일을 선택하세요. 파일명과 페이지 수를 확인한 후 '문서 분석'을 누릅니다.
PDF는 50MB, 100페이지 이하를 지원합니다. 잠긴 PDF는 해제한 사본을 사용하세요.
내장 텍스트의 깨진 문자·항목명·필수값을 검사하고, 부족하거나 의심되는 페이지는 한글/영어 OCR을 수행합니다. 선택 가능한 텍스트가 많아도 검사·죄명 대조가 필요하면 OCR을 추가합니다. 일부 문자만 있는 이미지 혼합 페이지나 잘못된 텍스트 레이어는 '모든 페이지를 OCR로 다시 읽기'를 선택하세요.
OCR은 느릴 수 있습니다. 완료할 때까지 창을 닫지 마세요. 어떤 글자든 틀릴 수 있으므로 원문 대조가 필요합니다.
분석 실패 시 오류를 표시하고 수동 입력을 허용합니다. 읽지 못한 정보를 분석 성공으로 취급하지 않습니다.

3. 검토와 수정
왼쪽에서 피고인별 이름, 죄명, 변호인 상태·이름, 구속 여부, 생년월일 앞 6자리, 기재 나이, 출생 연도 및 검사·기소일을 수정하세요.
변호인 없음/미기재는 빈칸입니다. X를 넣지 않습니다. OCR의 변호인 정보는 원문과 대조하여 상태를 선택하세요.
구속은 빨간 O, 불구속은 검은 X이며 피고인 순서대로 OX처럼 한 줄에 출력합니다. 구속이 미확정이면 생성할 수 없습니다.
주민번호 뒷자리는 계산에 사용하지 않습니다. 생년월일이 불확실하면 확인한 출생 연도를 YYYY로 입력하세요. 나이 불일치는 경고하며, 미확정 나이로 소년/필요적국선 원을 표시하지 않습니다.
기소일 기준 만 19세 미만은 소년, 만 70세 초과는 필요적국선에 빨간 투명 원을 표시합니다.
원문 대조 확인란을 선택하고 '메모 PDF 생성'을 누르세요. 내용을 수정하면 이전 생성물과 확인란이 무효화됩니다.

4. 미리보기와 저장·인쇄
오른쪽의 공소장/생성 메모/추출 텍스트를 전환하며 확인하세요. +/-로 확대·축소할 수 있습니다.
저장할 파일 이름을 입력하고 'PDF 다운로드'를 누르세요. Edge의 다운로드 폴더에 저장되거나 Edge 설정에 따라 위치 선택창이 열립니다.
다운로드한 PDF를 Edge로 다시 열어 모든 페이지·한글·원·O/X를 확인하고 Ctrl+P로 인쇄하세요.
칸에 들어가지 않는 내용은 자르지 않고 오류를 냅니다. 내용을 줄여 다시 생성하세요.
창을 닫으면 원문·검토 내용이 사라집니다. PDF를 먼저 저장하세요. 이미 다운로드한 PDF는 사용자가 직접 관리해야 합니다.

5. 인터넷 차단 점검 (대상 Windows에서 반드시 수행)
네트워크를 끈 뒤 새 Edge 창에서 HTML을 여세요. 개발 도구의 Network 기록에 외부 요청이 없는지 확인할 수 있습니다.
텍스트 PDF와 스캔 PDF를 각각 선택하고 분석·수정·생성·저장을 수행하세요. 저장한 PDF를 다시 열어 한글과 페이지를 확인하세요.
회사 PC에서 실제 file:// 테스트가 끝나기 전에는 운영 검증 완료 버전으로 취급하지 마세요.

6. 오류 대처
ERR_BLOCKED_BY_ADMINISTRATOR: 회사 관리자 정책의 로컬 파일 탐색 차단일 수 있습니다. IT 담당자에게 오류와 실행 경로를 전달하세요.
Worker / WebAssembly / CSP 오류: 회사 정책에서 로컬 HTML의 Blob Worker와 WebAssembly를 허용하는지 확인하세요.
다운로드 없음: Edge 다운로드 기록(Ctrl+J) 및 다운로드 차단 정책을 확인하세요.
OCR 부정확: 원문을 보며 수정하거나 다른 해상도의 스캔을 사용하세요. 인식되지 않은 정보를 임의로 확정하지 마세요.
브라우저 보안 해제, --disable-web-security 옵션, 관리자 정책 변경을 해결책으로 요구하지 않습니다.
승인 없이 EXE 또는 로컬 서버 방식으로 바꾸지 않았습니다.

7. 내부 구성
CriminalMemo.html: 실행 코드, PDF.js, Tesseract Worker/WASM, 한글·영어 OCR 데이터, PDF 생성 라이브러리, CMap·기본 글꼴, NanumGothic 한글 글꼴 및 템플릿 바이트를 모두 내장합니다.
assets/: 라이선스와 배포 메타데이터. templates/: 내장 템플릿과 동일한 원본 사본.
manifest.json: 배포 파일 SHA-256 목록. 실제 문서나 분석 결과는 배포물에 포함하지 않습니다.

8. v2.1 정밀 OCR·진단
기본으로 '검사·죄명을 영역 OCR로 대조'가 켜져 있습니다. 정상 내장 텍스트는 유지하면서 항목명·단어 위치에서 값 부분을 찾아 비교합니다. 전체 페이지를 무조건 OCR하지 않습니다.
정밀 OCR 설정에서 검사와 죄명에 서로 다른 PSM(한 줄/문단/흩어진 글자)과 한국어/한국어+영어를 선택할 수 있습니다. 설정은 다음 문서 분석에 적용합니다.
'텍스트·OCR 진단 및 후보 선택'에서 페이지와 단계를 선택하세요. 내장 텍스트, 전체 OCR 원문, 정밀 OCR, 처리 경로·시간·메모리 추정을 따로 볼 수 있습니다. 그 아래에는 항목별 후보·출처·페이지·영역·최종 선택·직접 수정값이 표시됩니다.
후보가 충돌하거나 필수 항목이 비어 있으면 자동 확정하지 않습니다. '원문 위치'로 해당 부분을 보고 '이 후보 적용'을 누르거나 검토 입력칸을 직접 수정하세요. 높은 신뢰도 점수가 정답을 보장하지 않습니다.

9. 마우스 영역 다시 인식
원문 미리보기로 전환하고 페이지를 선택하세요. '원문에서 마우스로 영역 지정'을 켜고 검사 이름이나 죄명 부분을 드래그합니다.
항목·대상 피고인·PSM·언어·전처리(원본/그레이/대비/적응형 이진화/기울기·노이즈)를 고르고 '선택 영역 다시 인식'을 누릅니다.
결과는 기존 값을 덮어쓰지 않고 정밀 OCR 후보로 추가됩니다. 후보를 선택하거나 직접 고치세요. 모든 문서에 같은 전처리가 유리하지 않습니다.
미리보기는 한 페이지씩 보여 메모리를 제한합니다. 페이지 선택으로 다른 페이지를 확인할 수 있으며 저장 PDF의 다른 원본 페이지는 유지됩니다.

10. 처리 한도와 한계
자동 OCR은 페이지당 최대 6회, 문서당 32회이며 새 OCR 시작 시간 예산은 120초입니다. 각 OCR 호출의 대기 제한은 30초입니다. 한도에 도달하면 원문 확인과 수동 보완이 필요합니다. 시간 한도는 브라우저 전체의 최악 실행시간 보장이 아닙니다.
전체 이미지는 최대 900만 화소, 영역 이미지는 최대 300만 화소로 제한합니다. 전체 브라우저·PDF 디코더·WASM의 최대 메모리를 보장하는 수치는 아닙니다.
원본이 90DPI처럼 낮거나 글자가 손상된 문서는 확대해도 정보가 복구되지 않을 수 있습니다. 읽지 못한 값은 추측하지 않습니다. 의미가 불분명한 죄명 줄바꿈도 직접 확인해야 합니다.
회귀·OCR 비교는 저장소 샘플과 합성 시험 문서에 한정됩니다. 실제 모든 회사 공소장의 정확도를 보장하지 않습니다.
