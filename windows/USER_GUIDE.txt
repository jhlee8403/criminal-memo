Criminal Memo — 첫기일 선택 입력 Windows/Edge 오프라인 시험판

지원 목표와 검증 범위
- 이번 빌드는 Microsoft Edge 104.0.1293.47을 대상으로 PDF.js 호환 빌드를 포함합니다.
- 실제 회사 Windows/Edge 104에서는 아직 실행하지 못했습니다.
- Linux Chromium 103의 실제 file:// 및 최신 Chromium에서 관련 API를 제거한 환경에서 PDF 읽기·미리보기·분석·자동 메모 생성·다운로드와 OCR 회귀를 검증했습니다.
- 회사 PC의 정확한 버전과 다운로드/로컬 파일 정책은 별도로 확인해야 합니다. 보안 기능을 끄거나 정책을 우회하도록 요구하지 않습니다.

1. 실행
새 시험판 ZIP을 압축 해제한 뒤 그 안의 CriminalMemo.html을 Edge로 여세요.
실행에 필요한 라이브러리, OCR 데이터, 글꼴과 양식은 HTML에 내장되어 있습니다.
사용자 PC에 Node.js, npm, Python, 별도 프로그램 설치, 서버 실행, 관리자 권한, 인터넷 연결을 요구하지 않습니다.
동봉된 템플릿 PDF와 라이선스 파일도 보존해 주세요. 이전 HTML과 새 HTML을 혼동하지 않도록 실행한 파일의 경로를 확인하세요.

2. 첫기일 입력 (선택 사항)
화면의 '첫기일 입력'에서 날짜를 YYYY-MM-DD, 시간을 24시간제 HH:mm으로 입력하세요.
예: 2026-11-18 / 10:00. 메모의 '기 일' 아래 칸에는 2026. 11. 18.과 10:00이 두 줄로 출력됩니다.
두 값 모두 비우면 기일 칸을 빈칸으로 둡니다. 하나만 입력하거나 날짜/시간이 잘못되면 생성하지 않고 오류를 표시합니다.
공소장 선택·분석 중에도 입력값은 유지됩니다. 분석 도중 첫기일을 수정할 수도 있습니다.
생성 후 입력값을 변경하면 기존 저장 버튼과 출력물을 무효화합니다. 최신 설정으로 '문서 분석'을 다시 실행하세요.
PDF 생성 도중 수정한 경우에도 이전 설정의 메모를 최신 결과로 보여 주지 않습니다.

3. PDF 선택과 문서 분석
'공소장 PDF'에서 로컬 PDF를 선택하세요. 오른쪽에 공소장 미리보기가 표시되고 '문서 분석' 버튼이 활성화되는지 확인하세요.
PDF는 50MB, 100페이지 이하를 지원합니다. 문서가 잠겨 있으면 읽을 수 있는 사본을 사용하세요.
'문서 분석'을 누르면 자동 추출 결과가 읽기 전용으로 표시됩니다.
텍스트가 거의 없는 페이지에는 기존 OCR이 적용됩니다. 필요하면 '모든 페이지를 OCR로 다시 읽기'를 선택할 수 있습니다.
OCR은 느릴 수 있습니다. 처리 중에는 창을 닫지 마세요. OCR 상태나 필수 정보의 불확실성 때문에 자동 생성이 보류될 수 있습니다.
첫기일 날짜·시간을 제외한 수동 입력이나 수정 기능은 제공하지 않습니다. 추출 실패 항목과 오류를 확인하세요.

4. 자동 메모 생성과 확인
필수 정보가 자동 추출되면 기존 1페이지 형사신건메모가 자동 생성됩니다.
국선변호인은 이름(국선), 일반 변호인은 이름, 법무법인은 법무법인명) 이름 이름 형식입니다. 없음/미기재는 빈칸입니다.
구속은 빨간 O, 불구속은 검은 X이며 피고인 순서를 유지합니다.
YYMMDD와 기재 나이/주민번호 뒷자리로 출생 세기를 추정하지 않으며, 생년월일 전체가 미확정이면 나이 원 표시를 보류합니다.
원문과 추출 결과, 생성 메모를 대조하세요. 긴 내용이 칸에 들어가지 않으면 잘라내지 않고 오류를 표시합니다.

5. 저장
'PDF 다운로드'를 눌러 생성된 메모를 저장하세요. 저장 위치 선택 여부는 Edge 설정을 따릅니다.
다운로드 기록(Ctrl+J)에서 파일을 열어 한글, 전체 이름, 날짜, O/X, 페이지 수를 확인한 후 인쇄하세요.
창을 닫으면 원문과 분석 결과는 메모리에서 사라집니다. 필요한 PDF를 먼저 저장하세요.

6. 오류 확인
Promise.withResolvers 오류가 계속 나오면 이번 ZIP 안의 새 CriminalMemo.html을 열었는지 확인해 주세요.
ERR_BLOCKED_BY_ADMINISTRATOR, Worker/WebAssembly/CSP 또는 다운로드 차단 오류는 오류 문구와 실행 파일 경로를 IT 담당자에게 전달하세요.
브라우저 보안 해제, --disable-web-security, 파일 접근 제한 우회 또는 관리자 정책 변경을 해결책으로 사용하지 마세요.
실제 회사 PC에서 네트워크를 끈 상태로 PDF 선택부터 미리보기·분석·생성·저장까지 확인하기 전에는 운영 검증 완료로 취급하지 마세요.
