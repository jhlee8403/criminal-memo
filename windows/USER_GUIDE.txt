Criminal Memo — 다운로드·피고인별 소년·국참 시험판

ZIP을 먼저 압축 해제한 뒤 CriminalMemo.html 하나를 Microsoft Edge로 여세요.
PDF 양식 2개, 글꼴, PDF 라이브러리, OCR 데이터가 HTML에 내장되어 있습니다.
인터넷, 별도 설치, 관리자 권한, 서버 실행은 필요하지 않습니다.
Edge 104.0.1293.47이 지원 대상이나 실제 회사 Windows Edge에서는 아직 검증하지 못했습니다.

1. 공소장 선택과 첫기일
PDF를 여러 개 선택하면 파일별 목록이 나타납니다. 다시 선택하면 목록이 교체됩니다.
파일명에 2026고단203948 또는 2025고정1382 같은 사건번호가 있어야 합니다.
사건번호가 없거나 서로 다른 사건번호가 여러 개면 생성하지 않습니다.
각 파일의 첫기일 날짜와 시간을 모두 입력하세요. 저장 파일명에 사용할 시간도 필수입니다.
날짜: 20261118, 2026-11-18, 2026. 11. 18. / 시간: 1000, 10:00
첫 번째 날짜를 바꾸면 나머지 모든 날짜에도 복사합니다. 시간은 복사하지 않습니다.
부분 입력, 존재하지 않는 날짜·시간은 오류로 표시합니다.
첫기일 외 다른 수동 입력은 제공하지 않습니다.

2. 전체 분석·메모 생성
파일을 차례로 분석하여 사건마다 정확히 2페이지짜리 PDF를 생성합니다.
첫 페이지: 기존 형사신건메모에 자동 추출된 정보·사건번호·첫기일을 기재합니다.
두 번째 페이지: 제공된 형사메모(2쪽).pdf의 원본 1페이지를 그대로 병합하며 아무 내용도 추가하지 않습니다.
검사·변호인·구속 여부 등 추출이 불확실한 항목은 빈칸으로 두고 목록에 추출 경고를 표시합니다.
정보를 전혀 읽지 못해도 파일명 사건번호와 입력한 첫기일로 메모를 생성합니다. 추측해서 채우지 않습니다.
파일명 사건번호 오류, 손상되거나 열 수 없는 PDF, 내장 양식 오류 등은 생성 오류로 표시합니다.
한 파일의 실패와 관계없이 나머지를 계속 처리합니다.
'이 파일 보기'와 공소장/생성 메모/추출 텍스트 버튼으로 확인하세요. 생성 메모에는 두 페이지 모두 표시됩니다.
첫기일을 바꾸면 해당 결과를 무효화합니다. 분석 중 변경한 입력의 이전 결과도 게시하지 않습니다.
기존에 저장한 파일은 그대로 남으므로 최신 입력으로 다시 생성하고 결과를 확인하세요.

3. 개별 저장 — 생성 PDF는 ZIP으로 묶지 않습니다
저장 파일명 예: 1000 2026고단203948.pdf
시간만 HHmm으로 앞에 붙이며 날짜나 ':'는 파일명에 넣지 않습니다.
사건번호와 시간이 같은 목록 항목은 이름 충돌 오류로 처리합니다.

우선: '저장 폴더 선택'에서 사용자가 직접 폴더를 지정합니다.
원본 공소장이 있는 폴더를 원하면 그 폴더를 직접 선택하세요. 파일 선택만으로 원본 경로를 알아내지 않습니다.
선택만으로 파일을 쓰지 않습니다. '이 메모 폴더 저장' 또는 '선택 폴더에 전체 저장'을 눌러야 저장합니다.
쓰기 권한을 허용한 폴더에만 저장하며 같은 이름의 기존 파일이 발견되면 덮어쓰지 않고 오류를 표시합니다.
원본 공소장을 수정하거나 삭제하지 않습니다. 충돌 시 다른 저장 폴더를 선택할 수 있습니다.
폴더 저장은 쓰기와 닫기가 성공한 뒤에만 '폴더 저장 완료'로 표시합니다.

대체: 회사 정책, 브라우저 또는 file 실행 제한으로 폴더 저장을 사용할 수 없으면 '이 메모 다운로드'를 사용하세요.
각 사건의 '이 메모 다운로드'를 누르거나, '다음 메모 다운로드' 버튼을 계속 눌러 순서대로 받으세요.
한 번 클릭할 때 PDF 하나만 요청합니다. 한 번의 클릭으로 여러 다운로드를 연속 실행하지 않습니다.
모든 건을 요청하면 다음 메모 버튼은 비활성화됩니다. 실제로 저장되지 않은 건은 각 사건의 다운로드 버튼으로 다시 요청하세요.
폴더 쓰기 권한을 허용한 경우에는 '선택 폴더에 전체 저장'으로 모든 파일을 순서대로 저장할 수 있습니다.
일부 저장 실패는 해당 행에 사유를 표시하고 나머지를 계속 저장합니다. 권한을 잃은 경우 나머지는 보류로 표시합니다.
'다운로드 요청됨'은 실제 저장 완료를 뜻하지 않습니다. Edge 다운로드 목록과 저장 폴더를 직접 확인하세요.
다운로드 저장 경로는 브라우저 설정/저장 대화상자가 정합니다.
프로그램 배포용 ZIP과 프로그램에서 생성하는 개별 PDF 저장은 별개입니다.

4. 구속·필요적국선·소년
구속은 빨간 O, 명시적 불구속은 검정 X, 미상은 빈칸입니다. 복수 피고인은 원래 순서대로 표시합니다.
고정 사건에서 구속여부 항목 자체가 없을 때만 기존 규칙대로 X를 적용합니다.
누구라도 구속이거나 확정 나이가 기소일 기준 70세 이상이면 필요적국선에 빨간 동그라미를 한 번 표시합니다.
소년은 피고인 순서대로 표시합니다: 만 19세 미만 빨간 O, 만 19세 이상 검정 X, 미확정은 해당 위치 빈칸.
예: 소년·성인은 OX, 성인·소년은 XO, 소년·미확정·성인은 O X입니다.
표시는 인쇄된 소년 글자 바로 위에 출력합니다. 나이 계산 기준은 첫기일이 아닌 기소일입니다.
주민등록번호 앞 6자리와 하이픈 뒤 첫 숫자만 이용합니다. 1·2는 1900년대, 3·4는 2000년대입니다.
나머지 뒷자리 여섯 숫자는 추출 텍스트에서 가리고 분석 결과·로그·메모에 저장하지 않습니다. 원본 PDF는 변경하지 않습니다.
등록번호가 불완전하거나 첫 숫자가 1~4가 아니면 보류하며, 기재 나이·다른 생년월일 항목으로 추측하지 않습니다.
OCR로 얻은 생년월일의 검토 필요 상태도 유지합니다. 기소일 누락·유효하지 않은 생일·미래 출생일은 보류합니다.
필요적국선은 누구라도 구속 또는 확정 만 70세 이상이면 기존 빨간 동그라미를 한 번 표시합니다.
국참은 특수상해·특수공갈·특정범죄가중처벌등에관한법률위반(도주치상/도주치사) 중 정확히 일치하는 죄명이 있으면 빨간 O입니다.
공백과 괄호 공백을 정규화하지만 다른 죄명을 부분문자열로 일치시키지 않습니다.
대상 죄명이 없고 모든 피고인의 죄명 정보가 완전할 때만 검정 X입니다. 누락·판독 불가·절단 등 불완전하면 빈칸입니다.
하나라도 대상 죄명이 확실하면 다른 피고인의 정보가 없어도 O를 표시합니다.
국참 표시는 지정된 죄명에 따른 자동 분류이며 국민참여재판 대상 여부의 최종 법적 판단이 아닙니다.
국선 이름(국선), 법무법인명) 이름 이름 형식은 유지합니다.

5. 검증 범위와 오류
텍스트가 거의 없는 페이지는 기존 OCR로 읽습니다. 전체 OCR 선택도 유지합니다.
OCR/텍스트 추출 실패는 경고로 표시하고 얻은 정보로 생성합니다. 읽기·양식·실제 PDF 생성 오류는 별도로 표시합니다.
PDF는 파일당 50MB, 1~100페이지를 지원합니다.
구형 Linux Chromium 103 및 최신 Chromium의 API 제거 환경은 개발 검증용이며 실제 회사 Edge 104 실행을 보장하지 않습니다.
File System Access API는 Chromium 계열의 보안 컨텍스트와 사용자 선택·권한이 필요하고 회사 정책에 따라 제한될 수 있습니다.
회사 Windows의 실제 폴더 선택·쓰기 정책은 직접 검증하지 못했습니다. 보안 기능을 해제하지 말고 개별 다운로드를 사용하세요.
창을 닫으면 메모리의 문서·분석 결과·폴더 선택은 사라집니다. 생성 결과를 확인하고 필요한 PDF를 먼저 저장하세요.
