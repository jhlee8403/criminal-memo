# Criminal Memo

형사신건메모 작성 프로그램

## 프로젝트 개요

형사사건 관련 자료와 사용자 입력 내용을 바탕으로 형사신건메모를 작성하는 프로그램입니다.

구체적인 기능, 문서 양식, 실행 환경은 추후 기획 단계에서 확정합니다.

## iPad 앱 1차 구현

SwiftUI / PDFKit / Vision 기반의 **iPadOS 17 이상** 앱입니다. 문서 분석과 PDF 생성은 기기 안에서 수행하며, 앱에서 외부 API를 호출하지 않습니다. 현재 상태는 1차 구현 및 Linux 핵심 테스트 검증 단계입니다. **Xcode 빌드·iPad 설치·Vision OCR·공유 동작은 아직 실행 검증되지 않았습니다.**

- 공소장 PDF 가져오기 → 텍스트 추출 또는 페이지별 OCR → 원문과 추출 결과 검토·수정 → 메모 생성 → PDF 미리보기·파일 저장·공유
- 피고인·죄명 번호 부여, 변호인 없음 X, 구속 빨간 O / 불구속 X
- 앞 6자리·기재 나이·기소일·사용자 확인 연도로 만 나이를 계산하여 소년(<19), 필요적국선(>70) 표시
- 저장소의 원본 양식을 그대로 번들에 포함하며, 원본 페이지를 벡터로 그린 뒤 지정 위치에 정보를 추가합니다. 원본 PDF 세 개는 이동하거나 수정하지 않았습니다.

자세한 빌드/설치 및 테스트: [개발 안내](docs/DEVELOPMENT.md)

실제 PDF 분석·정확한 좌표·검증 한계: [PDF 분석](docs/PDF_ANALYSIS.md)

### 프로젝트 구조

| 경로 | 역할 |
|---|---|
| `project.yml` | XcodeGen 프로젝트 정의 (Mac에서 `.xcodeproj` 생성) |
| `App/Views` | 가져오기, 원문·메모 미리보기, 검토·수정, 파일 저장·공유 |
| `App/Services` | PDFKit 읽기, Vision OCR, PDF 생성, 화면 상태 |
| `App/Resources/memo-template.pdf` | 원본 형사메모와 바이트가 동일한 앱 번들 리소스 |
| `Sources/MemoCore` | 필드별 추출 모듈, 검증, 나이 계산, 좌표 데이터 |
| `Tests/MemoCoreTests` | 실제 공소장 추출문과 핵심 로직 테스트 |
| `AppTests` | Apple 프레임워크 통합 테스트 (미실행) |
| `scripts/verify_pdfs.py` | 실제 PDF 좌표·원본 보존 검증 및 시뮬레이션 |

### 빠른 시작 (Mac)

```sh
brew install xcodegen
xcodegen generate
open CriminalMemo.xcodeproj
```

Xcode의 `CriminalMemo` 스킴과 iPad 시뮬레이터를 선택한 뒤 실행합니다. 실기기는 Signing Team과 고유 Bundle Identifier를 설정해야 합니다.

### 현재 범위와 제한

- 두 샘플의 명시된 항목에 맞춘 라벨 기반 추출입니다. 반복 라벨, 번호 목록, 띄어 쓴 라벨을 지원하지만 임의의 모든 공소장 양식·다단 문서를 보장하지 않습니다. 원문과 대조하는 검토 단계가 필수입니다.
- 텍스트가 거의 없는 페이지는 OCR로 전환하며, 잘못된 텍스트 레이어가 있는 문서는 “모든 페이지를 OCR로 다시 읽기”를 선택할 수 있습니다. 혼합 페이지의 이미지 영역만 자동 탐지하는 기능은 없습니다.
- 주민번호 뒷자리의 구분값·성별·체크섬을 사용하지 않습니다. 앞 6자리만 피고인 모델에 저장하고 기재 나이·기소일로 출생 세기를 해석합니다. 나이 불일치·정보 부족·OCR 판독 시 출생 연도를 확인하기 전에는 나이 동그라미를 표시하지 않습니다.
- 변호인은 피고인별로 저장합니다. 이름은 그대로, 없음 명시와 항목 미기재는 모두 X입니다. OCR·비어 있는 항목 등 판독 불확실 상태는 원문 대조 후 직접 분류해야 PDF를 생성할 수 있습니다.
- 복수 피고인의 죄명·변호인·구속을 구분합니다. 변호인·구속 칸의 번호는 피고인 번호와 대응하고, 죄명은 개별 번호에 해당 피고인 이름을 덧붙입니다.
- 전과·누범·집행유예·반의사불벌 등의 추출은 미구현이며, 독립 `CaseExtractionModule`로 추가하도록 설계했습니다.
- 50MB / 100페이지 제한, 암호화 문서 미지원. 칸을 넘는 텍스트는 생성을 중단하여 수정하도록 합니다. 사건 보관함·자동 저장 기능은 없습니다. 출생 연도와 기재 나이는 직접 수정할 수 있습니다.
- 작업 중 원문·추출문은 메모리에 보관하며 앱이 종료되면 사라집니다. 원문·추출문에는 원래 주민번호가 남지만, 피고인 모델에는 앞 6자리만 저장하고 출력 PDF에는 주민번호를 넣지 않습니다. 공유용 임시 PDF는 공유 화면 종료 시 삭제하며, iPad 잠금 시 파일 보호를 적용합니다. 사용자가 저장하거나 타 앱에 공유한 사본은 해당 위치에 남습니다.
